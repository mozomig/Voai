Voai

Local dictation and transcription for Mac

Download 1.9.1 GitHub
Free · Open source · macOS 14+, Apple Silicon
Dictation
Hold ⌥ Space or right ⌘ and speak
Insertion
At the cursor, without the clipboard
Speech models
Whisper, Parakeet TDT v3, GigaAM v3
Runs on
Your Mac’s GPU, offline
Editing, optional
Local GGUF, Ollama, LM Studio, OpenAI, Anthropic, Codex, Claude Code
Files
Speakers, timestamps, TXT, SRT

Free. Open source. Yours.

No account, no subscription, no paid tier. Every line of Voai is on GitHub under the MIT license. Read how insertion works, build it yourself, or send a fix.

# build it yourself
git clone https://github.com/mozomig/Voai
cd Voai
./scripts/package-macos
