FastEnhancer-B is the 16 kHz waveform streaming model from the upstream [DNS release](https://github.com/aask1357/fastenhancer/releases/tag/onnx-dns-v1.0.0). Voai embeds the released `fastenhancer_b.onnx` unchanged. SHA-256 is `e2d8758a91a5c7d59334fdd4b871900cbd311d6694d99d9e0a77662063e60434`. The model advances by 256 mono samples and retains five state tensors per recording. See the upstream [streaming reference](https://github.com/aask1357/fastenhancer/blob/main/docs/docs/onnx.md) and [license](LICENSE).
